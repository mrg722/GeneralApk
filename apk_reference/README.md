# apk_reference — respaldo de referencia (NO se usa en el juego)

`king_fighter_iii/bin/` es una copia de `assets/bin/` de la APK
"king-fighter-III-respaldo-funcional.apk" (datos propietarios `.bin`, PNG de UI,
WAV/MID). Se guarda solo como respaldo y referencia tecnica de calidad/diseno
(meta de ~24 frames por personaje). **Ningun archivo de aqui se carga ni se
distribuye con el juego**; el motor no los referencia. Son material de terceros:
si este repositorio es o sera publico, conviene sacar esta carpeta.
